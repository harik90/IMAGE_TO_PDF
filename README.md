# 🖼️ Images to PDF Converter (Web App)

A fast, secure, modern, and 100% client-side web application to convert multiple images (JPG, PNG, WEBP, GIF, SVG, BMP) into high-quality PDF documents.

## 🚀 Features

- **🔒 100% Private & Secure**: All image processing and PDF compilation happens entirely inside your browser. No files are uploaded to any server.
- **⚡ Multiple Image Formats**: Supports JPG, JPEG, PNG, WEBP, GIF, SVG, and BMP.
- **🔄 Drag & Drop Reordering**: Easily reorder pages/images with intuitive drag-and-drop.
- **📐 Page Size & Orientation**:
  - Auto (Fit to Image)
  - Standard Sizes: A4, A3, A5, Letter, Legal
  - Orientations: Portrait, Landscape, Auto
- **⚙️ Customization Controls**:
  - Margin adjustments (None, Small, Normal, Large)
  - Compression quality options (Original, High, Medium, Low)
  - Image scaling & fitting modes (Fit page, Fill page, Stretch, Original size)
  - Individual image rotation (90°, 180°, 270°)
- **🌓 Dark & Light Mode**: Clean, responsive, and modern UI that adapts seamlessly to your device.
- **📱 Fully Responsive**: Works smoothly on mobile phones, tablets, and desktop browsers.

## 💻 Local Usage

Simply open `index.html` in any modern web browser or serve it locally:

```bash
# Using Python
python -m http.server 8000

# Using Node.js (npx)
npx serve .
```
